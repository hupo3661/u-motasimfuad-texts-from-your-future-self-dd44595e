one funny text message from your future self, under 200 characters.

## The text

> Hey, it's you from 2031. The plant you bought to "become a plant person" died in 11 days. We never speak of it. The pot, however, is thriving.

(142 characters. Also saved in `entry.txt`.)

## Run

```sh
python3 main.py
```

Prints the text to stdout, nothing else. The program checks nothing
and writes no files: the line is one text, 142 characters, inside the
200-character gate.
